This is a repo that is supposed to help in the computational aspect of DNA circuts and chemical signaling. 

In the Schulman Lab at the Whiting School of Engineering, in the Chemical Engineering Department, Dr. Lindeman is working on using hydrogels for boolean expressions. 

This repo is made by Swetan Sinha, a current rising senior in high school. 

There are many folders here: 

1. Fipy_learning: This is a folder dedicated to helping one model Fipy Diffusion and understand the way Fipy Works. Fipy is a library that uses a Finite Volume method to solve PDEs.
   Inside there are files which help one see the numerical solution to 1D diffusion as well as the analytical solution and the overlay of the two. There is also a convergence study

2. Plots to Show Professor contains charts and plots that are important to the overall project.

3. Simple_model is a file that contains the code to simulate a well mixed bath. This is to check the chemical kinetics. Inside there is a folder of plots generated with obscure names.

4. student_sender.... is a surrogate that Professor Schulman provided which helps one understand the system and model some code for it

5. animations are just animations to help visualize the system.
